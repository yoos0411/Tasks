## Geek组Markdown学习任务笔记
### 1.基础理解
我认为**Geek**是在某个领域有近乎偏执的热爱，并且愿意为了这种热爱去深挖、去钻研、去较真的人。热爱是他们的内驱力。**Geek精神**我觉得有几个关键词：好奇心驱动，主动求知，乐于分享，不怕试错。
### 2.Github、Pull Request、Fork
-**Github**:基于Git的在线代码托管平台，用来保存代码、追踪版本，支持多人协作，也可以存放学习笔记、打搭建个人主页。
-**Fork**:在网页端把别人的仓库复制一份到自己的的账号下，得到独立副本，可以自己修改，不会改动原作者内容。

-**Pull Request**：修改完成后，向原仓库发起和并请求，等待原作者审核，是开源项目合作的核心方式。

这些词汇我是通过Github官方指南学到的。
### 3.初感受
第一次进入Github页面时，大量陌生名词直接唬到我了，感觉眼花缭乱，什么都不知道，后面按照友情提示里的官方指南一步步实操才慢慢弄懂。
